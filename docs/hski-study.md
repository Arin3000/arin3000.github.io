# HSKI 交互教程维护

文章：`source/_posts/hski-shader-painting.md`。它使用 `shader-study.ejs`，只有 `study: true` 的页面使用独立阅读布局。其他文章仍走原 Avalon 布局。

资源均为本站静态文件，不依赖 CDN：`source/assets/hski-study/`。

- `study.json` 包含十步讲解、源文件文本、段落行号和教学旁注。
- `code/` 为可下载的完整原始文件；旁注只在网页展示，不混入下载内容。
- `01.png`—`10.png` 是同一相机导出的逐层图。`full.png` 保留最终全身图。
- 修改映射时以原文件行号为准，不把展示旁注算入行号。

验证：运行 `npm run build`，再运行 `node tools/verify-hski-study.cjs`。后者检查源码字节哈希、代码范围、十步图片、眼睛分支、最终态比对、开篇四张图片与首页文章入口。验证脚本放在 tools/，避免被 Hexo 当成插件在构建前加载。

开篇 `#intro` 展示两张个人纯手工绘画理解，再展示两张官方角色参考，图片来自用户提供的原文件，均支持放大。绘画卡片可跳到对应 Shader 步骤；直接访问已有 `#step=...` 链接仍定位到教学代码。图片文件保存在 `paintings/`。

浏览器已人工验证：步骤导航、讲解跳代码、代码旁注回讲解、跨文件切换、查找、复制反馈、URL 锚点恢复、浏览器后退、图片放大、展示模式，以及 390px 窄屏的讲解/代码切换。对比滑块提供指针拖动和方向键/Home/End 操作。阅读步骤仅保存在当前浏览器，不发送到服务器。

教程使用 2026-09-10 的工程快照、夜间人物参数。环境层在该配置下贡献为零。图片是相机渲染，不是 Unity 编辑器全窗口截图。最终态一致性的结论限于本文固定镜头与参数。
